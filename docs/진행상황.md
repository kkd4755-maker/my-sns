## 레퍼런스 메모 (STEP 4-1)

1. 작성자 줄은 사진 위. 왼쪽에 동그란 프로필 사진, 그 옆에 굵은 이름
2. 사진은 정사각형, 카드 폭을 꽉 채움
3. 사진이 여러 장이면 오른쪽 위에 2/4 숫자, 사진 아래에 작은 점. 지금 사진의 점만 진하게
4. 글은 2줄까지 보이고 넘치면 "더 보기"
5. 올린 시각은 글 아래 작은 회색 글씨 (예: 3시간 전)
