# 요구사항

## 서비스 소개

- **주제**: 반려동물 일상
- **이름**: 멍냥일기
- **한 줄 소개**: 우리 집 멍멍이·냥이의 하루를 사진으로 남기는 곳

## 게시물 항목

| 항목 | 타입 | 설명 |
| --- | --- | --- |
| id | 숫자 | 게시물을 구분하는 고유 번호 |
| author | 문자열 | 올린 사람 |
| content | 문자열 | 글 내용 |
| images | 문자열 배열 | 사진 주소 목록 (1장 이상) |
| created_at | 문자열 | 올린 시각 |

## 화면

화면은 **피드 하나**뿐이다. 게시물 카드가 위에서 아래로 쌓인다.

카드 하나에는 작성자, 사진, 글, 올린 시각이 들어간다.

## 캐러셀 상태

| 상태 | 보이는 모습 |
| --- | --- |
| 사진 1장 | 사진만 보인다. 몇 번째 표시가 없고, 옆으로 넘겨지지 않는다 |
| 사진 여러 장 | 손가락(마우스 드래그) 또는 좌우 화살표 버튼으로 옆으로 넘긴다. 사진 오른쪽 위에 숫자(예: 2/4), 사진 아래에 점을 함께 보여준다. 지금 보는 사진의 점만 진하게. 다음 사진이 오른쪽에 살짝 보이고(사진 사이 8px), 마지막 다음엔 첫 장으로 돌아간다. 넘어가는 시간 0.5초 |

## 무한 스크롤 상태

| 상태 | 보여줄 문구 |
| --- | --- |
| 처음 불러오는 중 | 피드를 불러오고 있어요 |
| 더 불러오는 중 | 더 불러오는 중… |
| 더 없음 | 모든 게시물을 봤어요 |
| 오류 | 불러오지 못했어요 + "다시 시도" 버튼 |

## 분위기

밤 모드. 어두운 배경에 밝은 글씨, 주황→분홍 포인트로 사진이 돋보이는 느낌. 웰시코기 그림으로 귀여움을 더함.
(처음엔 포근한 크림톤이었으나 STEP 4-3 시안 비교에서 B안 밤 모드로 바꿈)

## 디자인 규칙

확정 시안은 `prototype/feed.html`. 값은 이 시안에서 그대로 옮긴 것이다.

| --- | --- | --- |

| 카드 | 모서리 24px, 테두리 2px point-line(그라데이션) |

### 사진과 글

- 사진은 정사각형(1:1). 넘치는 부분은 잘라서 찌그러지지 않게
- 글은 2줄까지 보이고 넘치면 "더 보기"
- 올린 시각은 "3시간 전" 형식

### 웰시코기 그림

- 직접 그린 SVG 그림. 카드 안(사진, 프로필)에는 넣지 않음. 카드 사진은 진짜 사진을 씀
- 서비스 이름 오른쪽: 웃는 얼굴 34px
- 상태 상자: 56px. 불러오는 중은 웃는 얼굴, 더 없음은 자는 얼굴, 오류는 땀 흘리는 얼굴
